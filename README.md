## Summary
This is a website created in Django (don't worry no tutorial was used in the creation of this project) for a fake store.
In the store you can Sign up, Sign in, deposit money into your account, buy various pictures, and view the pictures you have purchased.
This is all done through Hyperlinks, textfields, and buttons. No user URL shenanigans needed.

## Instalation
DISCLAIMER: All instructions are assuming Windows, if you have a different OS then please feel free to review the project on only the quality of this README

1. Download Python here : https://www.python.org/downloads/
2. Download Django through command line : python -m pip install Django
3. Download this repository into Visual Studio Code or other IDE (Note: if this does not work in other IDE please refer to the above disclaimer)
4. Navigate to the Directory above the FakeStore project folder and run : python manage.py makemigrations
5. Navigate to the Directory above the FakeStore project folder and run : python manage.py runserver
6. lastly open a browser and search for http://127.0.0.1:8000/. This should lead you to the FakeStore Website that you are currently hosting

## Using FakeStore
1. Select Sign Up to create a Profile
2. Enter a name into the textbox and submit
3. Select Sign In
4. Enter the same name you used to Sign up in the textbox and submit
5. Select deposit Money (or dont FakeStore accepts IOUs)
6. Enter the amount of money you would like to deposit
7. Select any of the Buy links to purchase pictures, you can buy in any order in any quantity (Purchases is limited in size so buying LOTS of pictures has unexplored consequenses)
8. If you wish to see the pictures you have bought then select the View Purchases link
